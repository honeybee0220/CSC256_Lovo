Cyber Guard 360

This project is an interactive web application designed to educate users on cybersecurity practices through simulations and real-time threat analysis. 

Project Files and Folders:
- main.html: The homepage of the website.
- aboutus.html: The About Us page with information about the mission and vision.
- courses.html: The Courses page with details on basic and advanced cybersecurity concepts.
- simulations.html: The Simulations page with interactive scenarios and real-time threat simulations.
- resources.html: The Resources page with links to important cybersecurity resources.
- styles.css: Main stylesheet for the website.
- main.js: JavaScript for the homepage functionality.
- courses.js: JavaScript for the Courses page slideshow.
- simulation.js: JavaScript for the Simulations page functionality.
- images/: Folder containing image files used in the project.
  - cyber-security1.jpg, cyber-security2.jpg, cyber-security3.jpg: Images for the homepage slideshow.
  - cyber-threats1.jpg, cyber-threats2.jpg, cyber-threats3.jpg: Images for the Courses page slideshow.
